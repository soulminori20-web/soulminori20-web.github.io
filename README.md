# Портфолио Дианы Тхайцуховой — v35

Готовая статическая версия портфолио графического и UX/UI-дизайнера. Сборка для просмотра и публикации не требуется.

## Как посмотреть

1. Полностью распакуйте архив в новую папку.
2. Откройте `index.html` двойным щелчком. Не открывайте файл внутри ZIP.
3. Проверьте главную страницу, четыре кейса, страницу мастерской и `assets/docs/diana-tkhaytsukhova-resume.pdf`.

При установленном Node.js можно запустить локальный сервер командой `npm run dev` и открыть `http://localhost:4173`. Установка npm-пакетов не нужна.

## Как обновить GitHub Pages

1. В GitHub Desktop выберите репозиторий `soulminori20-web.github.io` и нажмите **Show in Explorer**.
2. Сохраните резервную копию текущих файлов сайта.
3. Скопируйте содержимое распакованного архива в папку репозитория с заменой файлов. Папку `.git` не удаляйте и не заменяйте.
4. В GitHub Desktop проверьте Changes и укажите Summary: `Обновление портфолио v35`.
5. Нажмите **Commit to main**, затем **Push origin**.
6. Дождитесь успешного завершения GitHub Actions и обновите сайт сочетанием Ctrl+F5.

Важно: копируйте весь комплект, а не только HTML. Шрифты, изображения, скрипты и резюме находятся в `assets`.

## Что изменено в v35

- Первый экран сразу показывает специализацию, типы задач, производственный опыт и основные программы.
- Добавлен блок краткого опыта с прямыми ссылками на подтверждающие кейсы.
- Бегущая строка дополнена UX/UI, web, полиграфией, editorial, упаковкой, навигацией, препрессом, digital и AI-инструментами.
- Во всех карточках избранных проектов указаны роль, срок и результат.
- Все четыре кейса перестроены по единой логике: задача, роль, выполненные работы, процесс, типографика, программы, срок и результат.
- Удалены формулировки «концептуальный проект», «готов к реализации» и будущие проверки перед запуском.
- «Язык взаимопонимания» обозначен как реализованная дипломная работа.
- В «Северной заре» раскрыты многостраничные каталоги для инженерных выставок, упаковка, работа с ТЗ, цветом, типографиями и производством.
- Остальные работы получили раскрывающиеся компактные кейсы вместо просмотра одной картинки.
- Все проекты отмечены как реализованные.
- Блок коммерческого опыта дополнен результатами и ссылками на проекты.
- В навыки добавлены полиграфия, editorial, упаковка, офисный пакет, корпоративные экосистемы и автоматизация.
- Мастерская убрана из основного потока профессиональных кейсов и оставлена компактной дополнительной практикой в конце «Обо мне»; полная страница сохранена.

## Проверка

- Локальные ссылки и ресурсы проверяются командой `python tools/check.py`.
- Исходные тексты кейсов находятся в `tools/projects.json`.
- Главная страница и шаблоны кейсов находятся в `tools/render.py`.
- Оформление и адаптивность находятся в `assets/css/styles.css`.

Публикация в GitHub в рамках этой версии не выполнялась.
