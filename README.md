# Портфолио Дианы Тхайцуховой - v34

Готовая статическая версия портфолио графического и UX/UI-дизайнера. Сборка для просмотра и публикации не требуется.

## Как посмотреть

1. Распакуйте архив полностью в новую папку.
2. Откройте `index.html` двойным щелчком. Не открывайте файл прямо внутри ZIP.
3. Проверьте главную, четыре кейса, мастерскую и файл `assets/docs/diana-tkhaytsukhova-resume.pdf`.

При установленном Node.js можно запустить локальный сервер командой `npm run dev` и открыть `http://localhost:4173`. Установка npm-пакетов не нужна.

## Как обновить GitHub Pages

1. В GitHub Desktop выберите репозиторий `soulminori20-web.github.io` и нажмите **Show in Explorer**.
2. Сохраните резервную копию текущих файлов сайта.
3. Скопируйте **содержимое** распакованного архива в папку репозитория с заменой файлов. `index.html`, `assets`, `projects` и `workshop.html` должны лежать на верхнем уровне рядом друг с другом. Папку `.git` не удаляйте и не заменяйте.
4. В GitHub Desktop проверьте список Changes и напишите в поле Summary: `Обновление портфолио v34`.
5. Нажмите **Commit to main**, затем **Push origin**.
6. Дождитесь зелёной отметки в GitHub Actions. Для Pages должны быть выбраны ветка `main` и папка `/ (root)`.
7. Откройте `https://soulminori20-web.github.io/` и обновите страницу сочетанием Ctrl+F5.

Важно: копируйте не только HTML. Шрифты, изображения, анимации и резюме находятся в `assets`.

## Контроль глазами рекрутера

- Специализация и готовность к работе видны на первом экране.
- Избранные кейсы открываются сразу и идут в заданном приоритетном порядке.
- В каждом кейсе отделены авторский вклад, логика решения и готовность к реальному запуску.
- Реализованные работы не смешаны с концептуальными.
- Контакты и резюме доступны на первом экране и в финальном призыве к действию.
- Неподтверждённые проценты, исследования и бизнес-метрики не добавлялись.
- У длинных изображений нет фиксированного обрезания; все работы открываются крупнее.

## Для дальнейшего редактирования

- `tools/render.py` - разметка страниц и основные тексты.
- `tools/projects.json` - содержание четырёх кейсов и подписи изображений.
- `assets/css/styles.css` - оформление, анимации и адаптивность.
- `assets/js/main.js` - взаимодействия, вкладки, карусель и реакции маскота.
- `tools/make_profile.py` - генератор резюме.

Пересобрать страницы: `python tools/render.py`. Обновить PDF: `python tools/make_profile.py`. Проверить локальные пути: `python tools/check.py`.
