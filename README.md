# Портфолио Дианы Тхайцуховой · версия 29

Обновлённая версия сайта для поиска работы в графическом дизайне и UX/UI. Порядок проектов и разделов сохранён. Сайт работает без сборки, регистрации и внешних библиотек.

## Как посмотреть

Распакуйте архив и откройте `index.html` в браузере. Все страницы, изображения и PDF находятся внутри пакета. Для проверки через локальный сервер при установленном Node.js выполните `npm run dev` и откройте `http://localhost:4173`.

## Как обновить существующий сайт

В этой работе версия на Netlify не изменялась. Для публикации используйте существующий проект Netlify: подготовьте папку с `index.html`, `workshop.html`, папками `projects` и `assets` и загрузите её как новую версию сайта. `index.html` должен находиться непосредственно в корне загружаемой папки. Файлы README, CHANGELOG, package.json и папка tools нужны для редактирования и не требуются при публикации.

После публикации проверьте главную страницу, ссылки на проекты, скачивание PDF и контакты. Профиль PDF содержит адрес существующего сайта `soulminori.netlify.app`.

## Что находится в пакете

- `index.html` — главная страница, портфолио, информация о дизайнере и контакты.
- `projects/*.html` — четыре самостоятельные страницы проектов.
- `workshop.html` — творческая мастерская «Хуторок».
- `assets/docs/diana-designer-profile.pdf` — одностраничный профессиональный профиль с контактами.
- `assets/img` — исходные изображения из пакета сайта и оптимизированные варианты. Не включённые в галереи изображения также сохранены.
- `assets/css/styles.css`, `assets/js/main.js` — оформление и взаимодействия.
- `tools` — исходный генератор страниц и вспомогательные скрипты.
- `CHANGELOG.md` — выполненные изменения и оставшиеся содержательные задачи.

## Редактирование

Для простых изменений можно редактировать готовый HTML/CSS. Генератор `tools/build.py` перезаписывает HTML: если планируете использовать его, меняйте тексты непосредственно в нём. `tools/original-projects.json` сохраняет данные старой версии для чтения списка изображений; актуальные тексты находятся в `tools/build.py`.

Для генератора требуется Python 3.10+ и Pillow. Для повторного создания PDF дополнительно нужны ReportLab и Matplotlib. Установите зависимости из `tools/requirements.txt`, затем из корня проекта выполните `python tools/build.py`. Для оптимизации изображений — `python tools/optimize.py`, для PDF — `python tools/make_profile.py`. Готовому сайту эти инструменты не нужны.
